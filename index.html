Okay so I understand that these hints are really bad and the rules for them kinda change from guess to guess but I’ll try my best to explain each and MOST of the time they stay true to that.
Category: Quote/Moment if it’s a quote or moment. Person if it is a person, dead, alive, real, or not real. Game Related if it is a THING from a video game. If it is a person from a video game it does under the Person category. Thing/Idea if it is an object or intangible item. Song if it is a song.
Era: There are three eras. 2020-2022, 2023-2024, and 2025-present. If something spans over multiple eras, it will be placed in the most relevant category.
Status: If the category is Person, are they alive or dead? This includes spiritually as well.
Color: Probably the most useless hint, what color does this thing FIRST remind me of? There are two groups of colors: Red, Orange, Yellow, Green, Blue, Purple, and Pink and the other group is every other color. If the color is in the same group it will be yellow.
Rating: What would I rate this thing 0 to 5?
